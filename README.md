# 📊 Data Analyst Portfolio

A modern, responsive portfolio website showcasing my data analytics projects, dashboards, technical skills, and professional journey. Built using **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, this portfolio highlights real-world analytics projects involving **Python**, **SQL**, **Power BI**, **Tableau**, and **Excel**.

## ✨ Features

- 📌 Responsive design for desktop, tablet, and mobile
- 🎨 Modern UI with smooth animations
- 👨‍💻 About Me section
- 💼 Featured Data Analytics Projects
- 🛠 Technical Skills
- 📈 Interactive project showcase
- 📄 Resume download
- 📬 Contact section
- 🔗 GitHub & LinkedIn integration



## 📂 Featured Projects

### 📊 Job Market Intelligence Analysis
- Collected and analyzed **4,580+ live job postings** using the Adzuna API.
- Extracted **80+ technical skills** and identified hiring trends.
- Built an interactive Power BI dashboard.

### 📉 Telecom Customer Churn Analysis
- Analyzed **7,043 customer records**.
- Developed an interactive Tableau dashboard.
- Identified customer churn patterns and business insights.

### 💰 Revenue Analysis of US Largest Companies
- Cleaned and analyzed revenue data of the **100 largest U.S. companies**.
- Performed exploratory data analysis using Python and Pandas.
- Created 15+ business visualizations.

### 🗄 SQL Data Cleaning & Analysis
- Cleaned **2,000+ records** using PostgreSQL.
- Applied Joins, CTEs, Window Functions, and Aggregate Functions.
- Generated business insights through SQL analysis.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ishavade1/portfolio.git
```

Navigate to the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
